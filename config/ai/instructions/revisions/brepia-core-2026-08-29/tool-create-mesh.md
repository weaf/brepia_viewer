Create a 3D mesh from text and/or reference images. The mesh backend is already selected by Brepia and must not be changed. Local Creative backends currently support generation only; follow-up editing of an existing locally generated mesh is deferred, so do not pass meshId for local backends or claim that a local mesh was edited. A tool error means the mesh was not created or changed: never claim success unless this tool returns an output with id and fileType. After a successful output, do not invent, construct, or emit asset URLs or download links; Brepia presents the mesh and all download options in the model viewer. IMPORTANT: if create_mesh returns a tool error, do not call create_mesh again automatically in the same user turn. Treat the backend failure as terminal for that turn, explain the failure concisely to the user, and wait for the user to retry after the runtime/configuration problem has been fixed.
